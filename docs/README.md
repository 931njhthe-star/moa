**범위 구분:** MOA는 5인 팀 프로젝트이고, 노지훈의 주요 담당 범위는 Auto Healing(장애 감지·진단·복구·검증, 장애 주입 및 운영 관측)입니다. 원본 개발 기록은 `dev` 브랜치에서 확인할 수 있습니다.

**검증 주의:** 장애 시험 150회 중 148회 성공은 시험자 보고 기준입니다. 회차별 로그 및 시간 기록이 없어 독립적으로 검증된 운영 지표로 제시하지 않습니다.
